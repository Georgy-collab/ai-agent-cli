# AI-агент CLI

Терминальный помощник на Python. Понимает задачу на обычном языке, сам выбирает инструмент и сохраняет краткое резюме диалога в `agent/memory.json`.

Модель ходит в OpenAI-совместимый шлюз [ProxyAPI](https://proxyapi.ru): `https://api.proxyapi.ru/openai/v1`, модель `gpt-4o-mini`.

## Возможности

| Задача | Инструмент |
| --- | --- |
| Найти информацию в интернете | `web_search`: сначала HTML-выдача DuckDuckGo. Если сайт отвечает антибот-страницей без результатов, агент берёт заголовки Google Новостей и краткую статью Википедии |
| Вызвать внешний HTTP API | `requests` (`http_request`) |
| Прочитать, записать, показать рабочие файлы | `read_file`, `write_file`, `list_directory` — только папка `files/` |
| Погода по названию города | Open-Meteo: геокодинг, затем текущая погода |
| Курс валюты ЦБ к рублю | Банк России, `XML_daily.asp` (`cbr_rate`: USD, EUR и другие коды) |
| Курс криптовалюты | CoinGecko (`crypto_price` → число и короткая строка) |
| Локальная команда | PowerShell (`run_shell`), рабочая папка — `files/` |
| Память между запусками | `agent/memory.json` |
| QR-код | `generate_qr`: библиотека `qrcode`, классические квадратные модули в консоли, файл не создаётся |

Если городу, монете или пути не хватает ясности, агент задаёт уточняющий вопрос и не подставляет значение сам.

Чтение и запись файлов разрешены только в каталоге `files/` в корне проекта. Запрос прочитать или сохранить файл в другом месте отклоняется. Имя можно передавать как `notes.txt` или как `files/notes.txt` — оба варианта указывают на `files/notes.txt`. Команды оболочки тоже запускаются из `files/`, поэтому созданные ими файлы оказываются там же.

Файлы с секретами (`.env`) инструменты не читают и не перезаписывают. Команды вроде форматирования диска, выключения компьютера и рекурсивного удаления отклоняются. Оболочка обрывается через 30 секунд. Память диалога (`agent/memory.json`) и лог (`agent/logs/agent.log`) лежат отдельно и через файловые инструменты не открываются.

## Структура

```
run.py                  # запуск из корня: python run.py
requirements.txt
.env                    # PROXYAPI_API_KEY
files/                  # единственная папка рабочих файлов агента
agent/
  ├── agent.py          # цикл выбора инструментов
  ├── tools.py          # инструменты, включая погоду и крипту
  ├── memory.json       # долговременная память
  ├── run.py            # тот же CLI
  └── logs/agent.log    # появляется после первого запуска
```

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python run.py
```

Один вопрос без интерактивного режима:

```bash
python run.py Какая погода в Москве?
python run.py Сколько стоит Bitcoin в рублях?
```

То же самое из каталога агента: `python agent/run.py`.

Ключ читается из `.env` в корне (уже используется имя `PROXYAPI_API_KEY`). Дополнительно можно положить ключ в `agent/.env` — он перекрывает корневой. Подходит и имя `OPENAI_API_KEY`. Пробелы вокруг значения обрезаются.

Необязательные переменные:

```
PROXYAPI_BASE_URL=https://api.proxyapi.ru/openai/v1
PROXYAPI_MODEL=gpt-4o-mini
```

В диалоге: `/help`, `/memory`, `/clear`, `/exit`.

## Логи

Служебные сообщения пишутся только в `agent/logs/agent.log`: запрос, выбранный инструмент и укороченный результат. В командную строку попадает лишь диалог с агентом.

Сам ключ в лог не пишется.
